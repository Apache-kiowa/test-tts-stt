Подключение к LiteLLM

LiteLLM → Models → Add Model. Одна запись подходит для любой модели из списка выше.

Нажмите на значение, чтобы скопировать. Test Connect для озвучки может ругаться и при рабочей настройке — проверяйте командой ниже или на странице «Тест».

Словарь произношений

Применяется до остальной нормализации во всех моделях. Формат: что => как читать, по одному правилу в строке. Регулярное выражение: re: шаблон => замена. Строки с # — комментарии.

Голоса-образцы

Нужны ESpeech и F5 (без образца они не говорят), остальным — по желанию. Положите WAV на 5–12 секунд и точную расшифровку.
